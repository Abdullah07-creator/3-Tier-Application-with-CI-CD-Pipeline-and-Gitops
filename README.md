# End-to-End 3-Tier Application with CI/CD & Kubernetes

## Architecture Overview
This project contains a lightweight microservices task manager application:
* **Frontend:** HTML5/JS Client Dashboard (Port 3000/80)
* **Backend:** Python FastAPI REST API (Port 8000)
* **Database:** PostgreSQL Relational Database (Port 5432)

## Directory Layout
* `frontend/` - Web presentation assets
* `backend/` - REST API logic and dependencies
* `database/` - Database initialization scripts
